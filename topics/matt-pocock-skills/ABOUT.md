Matt Pocock's "idea to ship" workflow for coding agents: grill, spec, tickets, TDD, review, retro, and the Claude Code skills that run each step. Assumes you already use Claude Code daily and know what context and harness engineering are (see Agent Orchestration).

After this Topic you can:

- Name the four agent failure modes the skills are designed against, and the skill that fixes each
- Walk the main flow from memory and know when to branch off it: the prototype detour, single versus multi-session, on-ramps such as `/triage` and `/diagnosing-bugs`
- Choose the right move at a phase boundary: continue, `/clear`, `/handoff`, a subagent, `/compact`
- Install the plugin, run `/setup-matt-pocock-skills`, and take one real feature through the flow on a project of your own
