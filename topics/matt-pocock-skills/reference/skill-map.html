Main flow: idea → ship

Keep grill → spec → tickets in one unbroken context. Each /implement starts fresh.

Catalogue

SkillWhoWhat it does
Align
/grill-with-docsuserInterview that also updates GLOSSARY.md and ADRs. Use it in a repo.
/grill-meuserSame interview, stateless. Use it without a repo.
/grillingmodelThe interview primitive: design tree, rounds, frontier
/prototypemodelThrowaway code that answers one design question
/researchmodelA background agent writes a cited Markdown file from primary sources
Plan
/to-specuserTurns the conversation into a spec on the tracker. No interview.
/to-ticketsuserSplits the plan into tracer-bullet tickets with blocking edges
Build
/implementuserBuilds a spec or ticket: /tdd, then /code-review, then commit
/implement-specuserBuilds a whole spec as a task graph with parallel subagents on one integration branch
/tddmodelRed → green, one vertical slice at a time, only at pre-agreed seams (refactor step removed June 2026; refactoring now lives in /code-review)
/code-reviewmodelReviews the diff on two axes, Standards and Spec, in parallel subagents
/prmodelPR body: smallest visual, before/after evidence, one-way or two-way door call
Improve
/retrouserSuggests fixes to the agent's environment after a session
/improve-codebase-architectureuserSurveys the codebase for deepening opportunities. Run it every few days.
/codebase-designmodelDeep-module vocabulary: module, interface, depth, seam, adapter
/domain-modelingmodelSharpens domain terms in GLOSSARY.md and records ADRs
On-ramps (they join the main flow)
/triageuserTurns raw issues you didn't write into agent-ready ones
/diagnosing-bugsmodelFor hard bugs: get a red feedback loop, then minimise → hypothesise → instrument → fix
/wayfinderuserMaps work too big for one session as decision tickets
Session tools
/handoffuserWrites a portable doc for a new harness, directory or colleague
/wait-whatuserRe-explains the agent's last message in plain English
/ask-mattuserRouter: "which skill fits my situation?"

user = runs only when you type it, and orchestrates. model = the agent may also pick it up, and it holds reusable discipline. A user-invoked skill may call model-invoked skills, but never another user-invoked one.
