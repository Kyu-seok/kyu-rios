Rules worth memorising

  • Order exists within a partition, never across a topic.
  • Same key means same partition. Different keys may still share one.
  • Total order across a topic needs exactly one partition.
  • Partition count can only increase. To reduce it, create a new topic.
  • Growing remaps keys, and existing data does not move.
