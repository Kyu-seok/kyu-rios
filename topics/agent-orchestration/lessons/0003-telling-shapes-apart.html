Lesson 3 · Agent Orchestration

Telling the Six Shapes Apart

Don't memorise six definitions. Ask a few questions, in order.

Your win for this lesson

Read a short scenario and reach the right shape by asking the decision key questions below, in order.

1. The decision key

Ask these questions in order and stop at the first yes. Each one comes with clue words to look for in the scenario.

#AskIf yes →Clue words
1Does the model choose its own steps, with no fixed plan and no known number of steps?Autonomous agent"open-ended", "investigate", "nobody knows how many steps"
2Is there a check that sends the work back to be redone?Evaluator-optimizer"revise until", "feedback", "try again"
3Does each input go down only one of several branches?Routing"classify", "sort into", "send to the right…"
4Do several calls run at the same time, on a list you fixed in advance?Parallelization"three prompts", "simultaneously", "vote"
5Do several calls run, but a lead model decides what they are once it sees the input?Orchestrator-workers"lead model decides which…", "delegates", "unknown in advance"
6Otherwise: fixed steps one after another.Prompt chaining"first… then… then", "a check rejects"

The two traps

Parallelization vs orchestrator-workers. Both run many calls. The question is who writes the list of subtasks. If you wrote it in code before the input arrived, it's parallelization. If a model writes it after reading the input, it's orchestrator-workers.

Chaining vs evaluator-optimizer. Both can contain a check. A chaining gate lets the work continue or stops it. An evaluator sends it back to be redone. Look for an arrow pointing backwards.

2. See the key in the diagrams

Now look again at the diagrams with the key in mind: a backward arrow means an evaluator, one branch out of several means routing, and dashed workers mean the orchestrator decides them.

Evaluator-optimizer: the arrow goes back

Prompt chaining: a gate, but all arrows go forward

Parallelization: solid boxes you drew in advance

Orchestrator-workers: dashed boxes the model decides

3. Drill: ten quick scenarios

Work through the key for each one. After you answer, the feedback names the clue words that point to the right shape.

4. Recall

Close or scroll away from the table. Write the decision key questions in order.

  1. Model picks its own steps, unknown count? → Autonomous agent
  2. Work sent back to redo? → Evaluator-optimizer
  3. One branch out of several? → Routing
  4. Simultaneous, list fixed by you? → Parallelization
  5. Simultaneous, list decided by a model? → Orchestrator-workers
  6. Otherwise, fixed sequence → Prompt chaining
