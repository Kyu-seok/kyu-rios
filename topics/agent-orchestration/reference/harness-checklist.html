Harness Checklist

Agent = Model + Harness. When an agent fails, fix the harness, not just this one output.

When an agent fails, ask in order

  1. Preventable before it acts? → guide
  2. Detectable after? → sensor (write the message for the model: how to fix)
  3. Can a program decide it? → computational; needs judgment → inferential
  4. Must a fresh session know it? → state file or git

Rules of thumb

  • Guide ignored repeatedly → back it with a computational sensor.
  • Feedback alone repeats mistakes; feedforward alone is never checked. Use both.
  • The steering loop: a recurring failure means the harness needs to change ("add a sign on the slide").
