The Five Zoom Levels

One system, five questions. Find your level, then pick your technique.

Core definitions

Agent: "LLMs using tools based on environmental feedback in a loop," ending at a stop condition. Anthropic
Agent = Model + Harness. The harness is everything except the model. The inner harness ships with the tool; the outer harness is what you add. Böckeler

Rules of thumb

  • Start at the lowest level that works; add complexity "only when it demonstrably improves outcomes." Anthropic
  • Cost grows as you zoom out: agents use about 4× chat tokens, multi-agent about 15×. Anthropic
  • Graphs contain loops, and loops run inside harnesses. The levels overlap; ask which question am I solving?
